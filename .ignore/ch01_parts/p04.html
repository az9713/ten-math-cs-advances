4. The bridge: one sign radius controls everything — and the proof map

Theorems 1.1 and 1.2 look like different subjects — an optimization over packing certificates, and an uncertainty principle. This section proves they are the same subject: each admissible packing function manufactures a Fourier eigenfunction whose sign radius is controlled by the function's quality (Proposition F), and conversely a good pair of eigen-symmetric functions manufactures an admissible packing function (Proposition G). After these two bridges, everything reduces to a single question — how small can the sign radius of an eigenfunction vanishing at the origin be? — and the rest of the chapter answers it from both sides.

One small tool first. Applying the Fourier transform twice is not quite the identity but a reflection:

Lemma H (double transform). For $f \in \mathcal{S}(\mathbb{R}^d)$, $\;\widehat{\widehat f\,}(x) = f(-x)$. In particular, if $f$ is even — e.g. radial, meaning $f(x)$ depends only on $|x|$ — then $\widehat{\widehat f\,} = f$.

By Theorem 2.4 (inversion; applicable since $f, \widehat f \in \mathcal{S} \subset L^1$ by Proposition 2.5), $f(x) = \int \widehat f(\xi)e^{2\pi i x\cdot\xi}d\xi$. But by definition (1), $\widehat{\widehat f\,}(x) = \int \widehat f(\xi)e^{-2\pi i \xi\cdot x}d\xi$, which is the same integral at $-x$. ∎

4.1 Bridge one: packing certificates manufacture eigenfunctions

Proposition F (from admissible to anti-self-Fourier; eqs. (29)–(30)). Let $F \in \mathcal{A}_d$ be radial. Set $$a = \Bigl(\frac{\widehat F(0)}{F(0)}\Bigr)^{\!1/d} \gt 0, \qquad h(x) = F(ax), \qquad g = \widehat h - h.$$ Then $g \in \mathcal{S}(\mathbb{R}^d;\mathbb{R})$ is nonzero and satisfies $$\widehat g = -g, \qquad g(0) = 0, \qquad g(x) \ge 0 \;\text{ for } |x| \ge 1/a. \tag{30}$$ Consequently $r(g) \le 1/a$, so by definition (6), $$A_-(d) \;\le\; \Bigl(\frac{F(0)}{\widehat F(0)}\Bigr)^{\!1/d} \qquad\text{for every radial } F \in \mathcal{A}_d.$$

By the dilation rule (Lemma 2.2(ii)), $\widehat h(\xi) = a^{-d}\widehat F(\xi/a)$; in particular $$h(0) = F(0), \qquad \widehat h(0) = a^{-d}\widehat F(0) = F(0), \tag{29}$$ the second equality being exactly the choice of $a$. Now check the three properties of $g$:

Anti-self-Fourier. $\widehat g = \widehat{\widehat h} - \widehat h = h - \widehat h = -g$, using Lemma H ($h$ is radial, hence even).

Vanishing at the origin. $g(0) = \widehat h(0) - h(0) = 0$ by (29).

Exterior sign. For $|x| \ge 1/a$: $\widehat h(x) = a^{-d}\widehat F(x/a) \ge 0$ (admissibility of $F$), while $h(x) = F(ax) \le 0$ since $|ax| \ge 1$. So $g(x) = \widehat h(x) - h(x) \ge 0$.

Nonvanishing. Suppose $g = 0$, i.e. $h = \widehat h$. Then $h \ge 0$ everywhere (it equals $\widehat h = a^{-d}\widehat F(\cdot/a) \ge 0$) yet $h \le 0$ for $|x| \ge 1/a$; hence $h = 0$ outside the ball $B(0,1/a)$: $h$ is compactly supported. But then $\widehat h$ is real-analytic — for fixed $x' = (x_2,\dots,x_d)$, the function $z \mapsto \int_{|y| \le 1/a} h(y)e^{-2\pi i(z y_1 + x'\cdot y')}dy$ is entire in $z \in \mathbb{C}$ (differentiate under the integral over the compact support). Since $h = \widehat h$ vanishes for $x_1$ real and large (with $x'$ fixed), this entire function vanishes on an unbounded interval of the real axis — a set with limit points — so the identity theorem forces it to vanish identically. Varying $x'$: $h \equiv 0$. That contradicts $h(0) = F(0) \gt 0$ (§2.3). So $g \ne 0$. ∎

Read the inequality backwards: a lower bound on the sign radius $A_-(d)$ is automatically a lower bound on every Cohn–Elkies ratio, hence on $\mathrm{LP}_d$ itself. (The restriction to radial $F$ costs nothing — §5 shows rotational averaging preserves admissibility and the ratio.) This is how the "ceiling" half of Theorem 1.1 will be proved in §8. Figure 11 shows the bridge concretely in $d=1$ with the tent function of §3.3: there $a = 1$, and $g = \widehat h - h = \mathrm{sinc}^2 - \mathrm{tent}$ is visibly an anti-self-Fourier eigenfunction, vanishing at $0$, nonnegative past $r = 1$, with all its negative mass trapped inside the unit interval.

4.2 Bridge two: eigen-symmetric constructions manufacture certificates

Proposition G (from a Fourier pair to all three upper bounds). Suppose real radial Schwartz functions $f_-, f_+$ and a radius $R \gt 0$ satisfy $$\widehat{f_-} = f_+ \gt 0 \text{ everywhere}, \qquad f_-(0) = f_+(0), \qquad f_-(x) \lt 0 \;\text{ for } |x| \ge R.$$ Then:
(i) $F(x) = f_-(Rx)$ is admissible with $F(0)/\widehat F(0) = R^d$, so $\;\mathrm{LP}_d \le v_d (R/2)^d$;
(ii) $g_- = f_+ - f_-$ satisfies $\widehat{g_-} = -g_-$, $g_-(0)=0$, $g_- \gt 0$ for $|x| \ge R$, $g_-\ne 0$, so $\;A_-(d) \le R$;
(iii) if additionally a real radial Schwartz $f_0 \ne 0$ satisfies $\widehat{f_0} = f_0$, $f_0(0) = 0$, and $f_0(x) \gt 0$ for $|x| \ge R$, then $\;A_+(d) \le R$.

(i) By dilation, $\widehat F(\xi) = R^{-d} f_+(\xi/R) \gt 0$; in particular $\widehat F \ge 0$ and $\widehat F(0) = R^{-d}f_+(0) = R^{-d}f_-(0) = R^{-d}F(0) \gt 0$ (note $f_-(0) = f_+(0) \gt 0$ since $f_+ \gt 0$). And $F(x) = f_-(Rx) \lt 0$ for $|x| \ge 1$. So $F \in \mathcal{A}_d$ with ratio $F(0)/\widehat F(0) = R^d$; insert into definition (3).

(ii) $\widehat{g_-} = \widehat{f_+} - \widehat{f_-}$. By Lemma H, $\widehat{f_+} = \widehat{\widehat{f_-}} = f_-$, so $\widehat{g_-} = f_- - f_+ = -g_-$. At the origin $g_-(0) = f_+(0) - f_-(0) = 0$. For $|x| \ge R$, $g_-(x) = f_+(x) - f_-(x) \gt 0$ (positive minus negative). Nonzero for the same reason. Definition (6) gives $A_-(d) \le R$.

(iii) is Definition (6) verbatim. ∎

So one construction — a Fourier-transform pair and a self-Fourier function whose sign changes all happen at the same radius $R \approx \sqrt d/\pi$ — simultaneously caps $\mathrm{LP}_d$, $A_-(d)$, and $A_+(d)$. Building that construction is the whole of §9–§11 (Theorem 4.1). Combining the two bridges with the obstruction proved in §7–8 yields the two-sided squeeze:

$$\underbrace{\Bigl(\tfrac1\pi - o(1)\Bigr)\sqrt d}_{\text{obstruction, } \S7-8} \;\le\; \min\Biggl\{\, \inf_{F\in\mathcal{A}_d}\Bigl(\frac{F(0)}{\widehat F(0)}\Bigr)^{\!1/d},\; A_-(d),\; A_+(d) \Biggr\} \;\le\; \max\{\cdots\} \;\le\; \underbrace{R_{\epsilon,d} = \Bigl(\tfrac1\pi + o(1)\Bigr)\sqrt d}_{\text{construction, } \S9-11}$$
