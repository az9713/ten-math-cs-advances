1. Group von Neumann algebras from zero

Let $G$ be a countable discrete group. Its natural Hilbert space is $$\ell^2(G) \;=\; \Bigl\{ \xi : G \to \mathbb C \;:\; \textstyle\sum_g |\xi(g)|^2 \lt \infty \Bigr\},$$ with inner product $\langle \xi, \eta\rangle = \sum_g \xi(g)\overline{\eta(g)}$ and orthonormal basis $(\delta_g)_{g \in G}$, where $\delta_g$ is the indicator of $\{g\}$. Write $B(\mathcal H)$ for the algebra of bounded linear operators on a Hilbert space $\mathcal H$, $x^*$ for the adjoint of $x$ (defined by $\langle x\xi, \eta\rangle = \langle \xi, x^*\eta\rangle$), and $\mathcal U(\mathcal H)$ for the group of unitaries ($u^*u = uu^* = 1$). The group acts on its own Hilbert space twice over — from the left and from the right: $$\lambda(g)\,\delta_h = \delta_{gh}, \qquad \rho(g)\,\delta_h = \delta_{hg^{-1}} \qquad (g, h \in G).$$ Both are unitary representations, and they commute: $\lambda(g)\rho(k)\delta_h = \delta_{ghk^{-1}} = \rho(k)\lambda(g)\delta_h$ (Fig. 2).

Definition (commutant; group von Neumann algebra; trace). For a set $S \subseteq B(\mathcal H)$, the commutant is $S' = \{x \in B(\mathcal H) : xs = sx \text{ for all } s \in S\}$; it is always an algebra, closed under adjoints when $S$ is, and closed in every reasonable operator topology. The group von Neumann algebra of $G$ and its canonical trace are $$L(G) \;=\; \lambda(G)'' \;=\; \bigl(\lambda(G)'\bigr)', \qquad \tau(x) = \langle x\,\delta_1,\, \delta_1\rangle.$$ For a finite linear combination $x = \sum_g a_g \lambda(g)$ one gets $\tau(x) = a_1$: the trace reads off the coefficient of the identity. A von Neumann algebra is any $*$-subalgebra of some $B(\mathcal H)$ of the form $M = M''$ containing $1$; a factor is one whose center $Z(M) = M \cap M'$ is just the scalars $\mathbb C 1$; a II$_1$ factor is an infinite-dimensional factor carrying a faithful normal tracial state (for $L(G)$, the state $\tau$ below).

Think of $L(G)$ as the completion of the group ring: all “infinite sums” $\sum_g a_g \lambda(g)$ that still define bounded operators. Which infinite sums arise is subtle, but every element has well-defined Fourier coefficients, and they behave exactly like the finite case. Two elementary containments organize everything: $\rho(G) \subseteq \lambda(G)'$ (they commute), hence, taking commutants twice, $$\lambda(G) \;\subseteq\; L(G) \;=\; \lambda(G)'' \;\subseteq\; \rho(G)'.$$ So every $x \in L(G)$ commutes with all right translations — the only fact we will ever use about the double commutant.

Lemma A (Fourier coefficients). For $x \in L(G)$ define $a_g = \langle x\delta_1, \delta_g\rangle$, so $x\delta_1 = \sum_g a_g \delta_g$ with $\sum_g |a_g|^2 \lt \infty$. Then:
  1. $x$ is determined by $x\delta_1$: indeed $x\,\delta_h = \rho(h^{-1})\,x\,\delta_1 = \sum_g a_g\, \delta_{gh}$ for every $h$.
  2. $\tau$ is a faithful tracial state: $\tau(1) = 1$, $\;\tau(x^*x) = \|x\delta_1\|^2 \ge 0$ with equality only for $x = 0$, and $\tau(xy) = \tau(yx)$.
  3. If $x$ commutes with every $\lambda(h)$, then the coefficient function is constant on conjugacy classes: $a_{hgh^{-1}} = a_g$ for all $g, h$.

(1) $\delta_h = \rho(h^{-1})\delta_1$, and $x$ commutes with $\rho(h^{-1})$, so $x\delta_h = \rho(h^{-1})x\delta_1 = \rho(h^{-1})\sum_g a_g\delta_g = \sum_g a_g \delta_{gh}$. In particular $x\delta_1 = 0$ forces $x = 0$ on the basis, hence everywhere.

(2) $\tau(1) = \langle \delta_1, \delta_1\rangle = 1$ and $\tau(x^*x) = \langle x^*x\delta_1, \delta_1\rangle = \|x\delta_1\|^2$, which vanishes only when $x\delta_1 = 0$, i.e. $x = 0$ by (1). For traciality, let $y$ have coefficients $(b_g)$. First compute $x^*$'s coefficients: $\langle x^*\delta_1, \delta_g\rangle = \overline{\langle x\delta_g, \delta_1\rangle} = \overline{a_{g^{-1}}}$ by (1). Then $$\tau(xy) = \langle y\delta_1,\, x^*\delta_1\rangle = \sum_g b_g\, \overline{\overline{a_{g^{-1}}}} = \sum_g a_{g^{-1}}\, b_g,$$ an absolutely convergent sum of two $\ell^2$ functions (Cauchy–Schwarz). Exchanging the roles of $x$ and $y$ gives $\tau(yx) = \sum_g b_{g^{-1}} a_g$, the same sum after the substitution $g \mapsto g^{-1}$.

(3) $\lambda(h) x \lambda(h)^{-1} = x$ applied to $\delta_1$: since $\lambda(h)^{-1}\delta_1 = \delta_{h^{-1}} $, (1) gives $x\delta_{h^{-1}} = \sum_g a_g \delta_{gh^{-1}}$, and applying $\lambda(h)$ yields $\sum_g a_g \delta_{hgh^{-1}}$. Comparing coefficients of $\delta_{g'}$ with those of $x\delta_1$: $a_{h^{-1}g'h} = a_{g'}$. ∎

Now the criterion that decides when the shadow is a factor — the chapter's group-factor criterion [MN43]. Recall: $G$ is ICC if it is infinite and the conjugacy class $\{hgh^{-1} : h \in G\}$ of every $g \neq 1$ is infinite.

Proposition B (Murray–von Neumann ICC criterion). Let $G$ be an infinite countable group. Then $L(G)$ is a II$_1$ factor if and only if $G$ is ICC.

Fig. 3 draws the mechanism. Suppose $G$ is ICC and let $x$ lie in the center of $L(G)$. Then $x$ commutes with every $\lambda(h)$, so by Lemma A(3) its coefficient function $g \mapsto a_g$ is constant on conjugacy classes. But $\sum_g |a_g|^2 \lt \infty$: a function that takes a fixed nonzero value on an infinite set is not square-summable, so $a_g = 0$ on every infinite class. Since all classes except $\{1\}$ are infinite, $x\delta_1 = a_1\delta_1$, and Lemma A(1) gives $x = a_1 1$. The center is $\mathbb C 1$: a factor. It is infinite-dimensional (the $\lambda(g)$, $g \in G$, are linearly independent: applied to $\delta_1$ they give orthonormal vectors), and $\tau$ is a faithful tracial state by Lemma A(2) — a II$_1$ factor. (Normality of $\tau$ is inherited from the vector-state form $\tau = \langle\,\cdot\,\delta_1, \delta_1\rangle$.)

Conversely, suppose some $g_0 \neq 1$ has a finite conjugacy class $C$. Set $z = \sum_{g \in C} \lambda(g)$, a finite sum, hence in $L(G)$. For every $h$, conjugation by $h$ permutes $C$, so $\lambda(h) z \lambda(h)^{-1} = z$: thus $z$ commutes with $\lambda(G)$, i.e. $z \in \lambda(G)'$; and $z \in \lambda(G)''$ trivially. So $z$ is central. But $z\delta_1 = \sum_{g\in C}\delta_g$ is not a multiple of $\delta_1$ (as $1 \notin C$), so $z \notin \mathbb C1$ — the center is bigger than the scalars and $L(G)$ is not a factor. ∎

The amenable collapse (context, imported). Connes's classification of injective factors [Con76] implies that every amenable ICC group has $L(G) \cong R$, the unique hyperfinite II$_1$ factor. So on the amenable side the fiber of $G \mapsto L(G)$ is one gigantic class, and any rigidity must come from non-amenability. Property (T) — which is incompatible with amenability for infinite groups — was the standard-bearer for the opposite behavior. This background motivates but is not used in the proof of Theorem 1.2.

2. Property (T) and the Connes–Jones bridge

Property (T) was built from scratch in the Chapter 3 explainer (§3 there, with proofs of the basic calibrations); we restate the definition in the form used here and add the two facts this chapter needs. A unitary representation $\pi : G \to \mathcal U(\mathcal H)$ has almost invariant vectors if for every finite $F \subseteq G$ and $\varepsilon \gt 0$ there is a unit vector $\xi$ with $\max_{g \in F}\|\pi(g)\xi - \xi\| \lt \varepsilon$.

Definition (property (T); relative property (T); Kazhdan pair). $G$ has property (T) if every unitary representation with almost invariant vectors has a nonzero invariant vector. Equivalently (for $G$ generated by a finite set $F$): there is $\kappa \gt 0$ — a Kazhdan constant, making $(F, \kappa)$ a Kazhdan pair — such that every representation without invariant vectors satisfies $\max_{g\in F}\|\pi(g)\xi - \xi\| \ge \kappa\|\xi\|$ for all $\xi$. For a subgroup $A \le G$, the pair $(G, A)$ has relative property (T) if every representation of $G$ with almost invariant vectors has a nonzero $A$-invariant vector.
Proposition C ((T) passes to quotients). If $G$ has property (T) and $\varphi : G \twoheadrightarrow H$ is onto, then $H$ has property (T).

A representation $\pi$ of $H$ with almost invariant vectors pulls back to $\pi \circ \varphi$ on $G$, with the same vectors almost invariant (any finite $F \subseteq H$ lifts to a finite subset of $G$). Property (T) for $G$ gives a $\pi\circ\varphi$-invariant vector, which is $\pi$-invariant since $\varphi$ is onto. ∎

Import 5 (property-(T) inheritance) [BHV08]. Property (T) is preserved under passage to finite-index subgroups and finite-index extensions ($H \le G$ of finite index: $G$ has (T) iff $H$ does). Moreover every countable discrete property-(T) group is finitely generated. (Proofs run through induced representations; we import them.)

The second new ingredient is the bridge between the group and its factor. There is a notion of property (T) for a II$_1$ factor (Connes–Jones), designed so that the following holds:

Import 1 (Connes–Jones [CJ85]). An ICC group $G$ has property (T) if and only if the II$_1$ factor $L(G)$ has property (T) in the sense of Connes–Jones. In particular, if $L(G) \cong L(H)$ and $H$ is ICC with property (T), then property (T) of the common factor forces property (T) for the ICC group $G$.
Lemma 2.1. Let $G, H$ be countable discrete groups with $L(G) \cong L(H)$. If $H$ is ICC with property (T), then so is $G$.

$H$ ICC makes $L(H)$, hence $L(G)$, a II$_1$ factor (Proposition B). Applying Proposition B in the other direction: $G$ must be ICC ($G$ is infinite: a finite group has finite-dimensional $L(G)$). By Import 1 applied to $H$, the factor has property (T); by Import 1 applied to $G$, the group $G$ has property (T). ∎
