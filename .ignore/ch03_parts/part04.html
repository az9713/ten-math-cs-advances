5. The binary Leavitt algebra and its elementary groups

Analysis is over; from here the work is exact algebra, and every identity is both proved by hand and re-checked by machine in §9. Recall the ring from (1): $$R \;=\; L_{\mathbb F_2}(1,2) \;=\; \mathbb F_2\bigl\langle\, s_0, s_1, t_0, t_1 \;\big|\; t_i s_j = \delta_{ij},\; s_0 t_0 + s_1 t_1 = 1 \,\bigr\rangle.$$ Coefficients are mod $2$, so $+$ and $-$ coincide — a convenience we will exploit repeatedly. Since $R$ is generated as a ring by finitely many elements over a finite field, $R$ is countable, and so is its unit group $R^\times$.

5.1 The string model: what the generators do

The relations become transparent in a concrete representation. Let $W$ be the $\mathbb F_2$-vector space with one basis vector $e_\omega$ for each infinite binary string $\omega \in \{0,1\}^{\mathbb N}$, and define linear operators $$s_i\, e_\omega = e_{i\omega}, \qquad t_i\, e_{j\omega} = \delta_{ij}\, e_\omega \qquad (i, j \in \{0,1\}).$$ So $s_i$ prepends the bit $i$, while $t_i$ deletes a leading $i$ when present and kills the vector otherwise (Fig. 15).

Proposition I. These formulas satisfy the defining relations of $R$, so they extend to a representation of $R$ on $W$; and $R$ is infinite.

Check each relation on every basis vector. $t_i s_j e_\omega = t_i e_{j\omega} = \delta_{ij} e_\omega$, which is the first family. For the second, split by the leading bit: $(s_0 t_0 + s_1 t_1) e_{0\omega} = s_0 e_\omega + 0 = e_{0\omega}$, and symmetrically on $e_{1\omega}$; every basis vector starts with $0$ or $1$, so $s_0t_0 + s_1t_1$ acts as the identity. A map of generators preserving defining relations extends to the whole finitely presented ring. For infinitude: the operators $s_0^k$ send $e_{111\cdots}$ to the distinct vectors $e_{0^k 111\cdots}$, so the elements $s_0^k \in R$ have distinct images, hence are distinct. ∎

The same relations, packaged as rectangular matrices $S = (s_0 \; s_1)$ and $T = \binom{t_0}{t_1}$, read $ST = 1$ and $TS = I_2$: mutually inverse module maps between $R$ and $R^2$. So $R \cong R^2$ as right $R$-modules — the dimension-cheating self-similarity promised in §0 (an isomorphism of modules, not of unital rings). Everything below is this one identity, iterated along binary words.

5.2 Word calculus and prefix codes

For a finite binary word $a = i_1 \cdots i_r$ define $$s_a = s_{i_1} \cdots s_{i_r}, \qquad t_a = t_{i_r} \cdots t_{i_1}, \qquad e_a = s_a t_a,$$ with empty products equal to $1$. In the string model, $s_a$ prepends the word $a$, $t_a$ deletes it (killing strings that do not start with $a$), and $e_a$ is the projection onto the cylinder $[a]$: it fixes $e_\omega$ for $\omega \in [a]$ and kills the rest. Recall from §2.1: a prefix code $E = (a_1, \dots, a_q)$ lists words none of which is a prefix of another; it is complete if the cylinders $[a_i]$ partition all infinite strings. Write $e_E = \sum_i e_{a_i}$.

Lemma J (word calculus). For finite binary words $a, b$:
  1. $t_a s_b = s_{b'}$ if $b = ab'$; $\;t_a s_b = t_{a'}$ if $a = ba'$; $\;t_a s_b = 0$ if $a, b$ are prefix-incomparable. In particular, for a prefix code, $t_{a_i} s_{a_j} = \delta_{ij}$.
  2. $(s_{a_i} t_{a_j})(s_{a_k} t_{a_l}) = \delta_{jk}\, s_{a_i} t_{a_l}$ — the operators $s_{a_i} t_{a_j}$ multiply like matrix units $E_{ij}$.
  3. $e_a = e_{a0} + e_{a1}$; and $e_E = 1$ for every complete prefix code $E$.

(1) Peel one letter at a time: $t_a s_b = t_{i_r}\cdots t_{i_1} s_{j_1} \cdots s_{j_m}$ where $a = i_1\cdots i_r$, $b = j_1 \cdots j_m$. The innermost pair $t_{i_1}s_{j_1}$ is $\delta_{i_1 j_1}$ by the defining relation; if the letters agree it vanishes into $1$ and the next pair meets. Repeat while letters agree. If a disagreement occurs before either word is exhausted, a factor $t_is_j = 0$ ($i \neq j$) appears and everything is $0$ — that is the incomparable case. If $b$ runs out first (i.e., $b$ is a prefix of $a$, $a = ba'$), the leftover is $t_{a'}$; if $a$ runs out first ($b = ab'$), the leftover is $s_{b'}$. For a prefix code, distinct words are incomparable, giving $\delta_{ij}$.

(2) $(s_{a_i} t_{a_j})(s_{a_k} t_{a_l}) = s_{a_i}(t_{a_j}s_{a_k})t_{a_l} = \delta_{jk} s_{a_i}t_{a_l}$ by (1).

(3) $e_{a0} + e_{a1} = s_a s_0 t_0 t_a + s_a s_1 t_1 t_a = s_a(s_0t_0 + s_1t_1)t_a = s_a t_a = e_a$. For completeness: every complete prefix code arises from the one-word code $(\varepsilon)$ (empty word, $e_\varepsilon = 1$) by repeatedly replacing a word $a$ with its children $a0, a1$ — each cylinder $[a_i]$ of a complete code is reached by finitely many splits, and conversely any full set of splits keeps the cylinders a partition. Each split preserves $e_E$ by the identity just proved, so $e_E = 1$ throughout. ∎

Part (2) is the pivotal observation: a prefix code with $q$ words plants a full $q \times q$ system of matrix units inside $R$. Fig. 16 draws it. That is how matrix groups will live inside the unit group of a ring that never mentions matrices.

5.3 The corner isomorphism $\Theta_E$

Write $M_q(R)$ for $q \times q$ matrices over $R$, and recall $e_E = \sum_i e_{a_i}$ is an idempotent ($e_{a_i}e_{a_j} = \delta_{ij}e_{a_i}$ by Lemma J(2)), so $e_E R e_E$ is a (nonunital, unless $e_E = 1$) ring with unit $e_E$.

Proposition (the chapter's equation (2), generalized). For any prefix code $E = (a_1, \dots, a_q)$, the map $$\Theta_E : M_q(R) \longrightarrow e_E R e_E, \qquad (r_{ij}) \longmapsto \sum_{i,j} s_{a_i}\, r_{ij}\, t_{a_j}$$ is a ring isomorphism sending $I_q \mapsto e_E$, with inverse $x \mapsto (t_{a_i} x\, s_{a_j})_{i,j}$. If $E$ is complete, $e_E = 1$ and $\Theta_E : M_q(R) \xrightarrow{\;\sim\;} R$ is a unital ring isomorphism.

Multiplicative: $\Theta_E(r)\Theta_E(r') = \sum_{i,j,k,l} s_{a_i} r_{ij} (t_{a_j} s_{a_k}) r'_{kl} t_{a_l} = \sum_{i,j,l} s_{a_i} r_{ij} r'_{jl} t_{a_l} = \Theta_E(rr')$, using $t_{a_j}s_{a_k} = \delta_{jk}$ (Lemma J(1)). Additivity is clear, and $\Theta_E(I_q) = \sum_i s_{a_i}t_{a_i} = e_E$.

Inverse: for a matrix $(r_{ij})$, $t_{a_k} \Theta_E(r)\, s_{a_l} = \sum_{i,j} (t_{a_k}s_{a_i})\, r_{ij}\, (t_{a_j}s_{a_l}) = r_{kl}$. Conversely, for $x \in e_E R e_E$, $$\sum_{k,l} s_{a_k}(t_{a_k} x s_{a_l})t_{a_l} = \Bigl(\sum_k e_{a_k}\Bigr) x \Bigl(\sum_l e_{a_l}\Bigr) = e_E\, x\, e_E = x.$$ So the two maps are mutually inverse bijections between $M_q(R)$ and $e_E R e_E$. When $E$ is complete, $e_E = 1$ (Lemma J(3)). ∎

When $E$ is not complete, a unit $h$ of the corner ring $e_E R e_E$ (meaning $hh' = h'h = e_E$ for some $h'$) still yields a unit of all of $R$: the corner-unit extension $h + 1 - e_E$, with inverse $h' + 1 - e_E$ — multiply out, using $h e_E = e_E h = h$, and the cross terms vanish. In the string model, $h + 1 - e_E$ acts as $h$ inside the cylinders of $E$ and as the identity outside. (Characteristic $2$: $1 - e_E = 1 + e_E$; we keep writing the minus sign for readability.)

5.4 Elementary groups inside $R^\times$, and property (T)

Definition (elementary groups; elementary prefix groups). For a unital ring $A$ and $q \ge 2$, $\mathrm{GL}_q(A)$ is the group of invertible $q \times q$ matrices, and $\mathrm{EL}_q(A) \le \mathrm{GL}_q(A)$ is the subgroup generated by the elementary matrices $x_{ij}(r) = I_q + r E_{ij}$ for $i \neq j$, $r \in A$ ($E_{ij}$ = matrix unit; $x_{ij}(r)$ is invertible with inverse $x_{ij}(-r)$). For a prefix code $E = (a_1, \dots, a_q)$, the elementary prefix group is $$\mathrm{EL}_E(R) \;=\; \bigl\langle\, 1 + s_{a_i} r\, t_{a_j} \;:\; i \neq j,\; r \in R \,\bigr\rangle \;\le\; R^\times,$$ and its generators $1 + s_{a_i} r t_{a_j}$ are called elementary $E$-roots. (Each is a unit: its inverse is $1 - s_{a_i}rt_{a_j} = 1 + s_{a_i}rt_{a_j}$ in characteristic $2$ — the square is $1$ since $(s_{a_i}rt_{a_j})^2 = s_{a_i}r(t_{a_j}s_{a_i})rt_{a_j} = 0$ for $i \neq j$.)

The corner-unit extension identifies the two pictures: for $i \neq j$, $$(1 - e_E) + \Theta_E(I_q + rE_{ij}) \;=\; (1 - e_E) + e_E + s_{a_i}rt_{a_j} \;=\; 1 + s_{a_i} r\, t_{a_j},$$ so $\mathrm{EL}_E(R)$ is precisely the copy of $\mathrm{EL}_q(R)$ acting inside the cylinders of $E$ and identically outside; in particular $\mathrm{EL}_E(R) \cong \mathrm{EL}_q(R)$.

Lemma L (Steinberg identities, and finite generation). In $\mathrm{EL}_q(A)$ for any unital ring $A$:
  1. $x_{ij}(r)\,x_{ij}(r') = x_{ij}(r + r')$;
  2. $[x_{ij}(r),\, x_{jk}(r')] = x_{ik}(rr')$ for $i, j, k$ distinct, where $[x, y] = xyx^{-1}y^{-1}$.
Consequently, if $q \ge 3$ and $A$ is generated as a unital ring by a finite set $Z$, then $\mathrm{EL}_q(A)$ is generated by the finitely many elementary matrices $x_{ij}(z)$, $z \in Z \cup \{1\}$, $i \neq j$. For $A = R$, $Z = \{s_0, s_1, t_0, t_1\}$: the groups $\mathrm{EL}_q(R)$, $q \ge 3$, and hence all $\mathrm{EL}_E(R)$ with $|E| \ge 3$, are finitely generated.

(1) $(I + rE_{ij})(I + r'E_{ij}) = I + (r + r')E_{ij} + rr' E_{ij}E_{ij}$ and $E_{ij}E_{ij} = 0$ for $i \neq j$. (2) Expand: with $P = rE_{ij}$, $Q = r'E_{jk}$, one has $PQ = rr'E_{ik}$, $QP = 0$, $P^2 = Q^2 = (PQ)P = Q(PQ) = 0$; then $$(I+P)(I+Q)(I-P)(I-Q) = (I + P + Q + PQ)(I - P - Q + QP) = I + PQ$$ by direct expansion, all higher products vanishing. (This is where three distinct indices are needed — with only two, $QP \neq 0$.)

Generation: let $H \le \mathrm{EL}_q(A)$ be the subgroup generated by the $x_{ij}(z)$, $z \in Z \cup \{1\}$, and let $A_0 = \{r \in A : x_{ij}(r) \in H \text{ for all } i \neq j\}$. By (1), $A_0$ is closed under addition (and contains $0$, as $x_{ij}(0) = I$); by (2) with a third index $k$ (available since $q \ge 3$), $A_0$ is closed under multiplication; it contains $Z$ and $1$. The closure of $Z \cup \{1\}$ under $+$ and $\times$ is all of $A$ (over $\mathbb F_2$, ring-generation needs no extra scalars). So $A_0 = A$ and $H = \mathrm{EL}_q(A)$. ∎

Now the deep input that makes these groups useful: the Ershov–Jaikin-Zapirain theorem, a vast ring-theoretic generalization of Kazhdan's “$\mathrm{SL}_{d \ge 3}(\mathbb Z)$ has property (T)”:

Import 3 (Ershov–Jaikin-Zapirain) [EJ10, Thm. 1.1]. Let $A$ be any finitely generated associative unital ring and $n \ge 3$. Then $\mathrm{EL}_n(A)$ has property (T). (Their theorem covers the “noncommutative universal lattices” $\mathrm{EL}_n(\mathbb Z\langle x_1,\dots,x_k\rangle)$; every $\mathrm{EL}_n(A)$ with $A$ finitely generated is a quotient of one of these, and property (T) passes to quotients.)

5.5 The nine-leaf code and the groups $G$ and $\Gamma$

The specific configuration uses three prefix blocks of three words each (the chapter's equation (14)): $$\alpha = (000,\, 001,\, 01), \qquad \beta = (1000,\, 1001,\, 101), \qquad \nu = (1100,\, 1101,\, 111),$$ $$D = (\alpha_1, \alpha_2, \alpha_3,\, \beta_1, \beta_2, \beta_3,\, \nu_1, \nu_2, \nu_3). \tag{14}$$ The $\alpha$-cylinders partition $[0]$, the $\beta$-cylinders partition $[10]$, and the $\nu$-cylinders partition $[11]$ (check each by two splits: e.g. $[10] = [100] \sqcup [101] = [1000] \sqcup [1001] \sqcup [101]$). Hence $D$ is a complete nine-leaf code, while $\alpha$ is an incomplete code covering exactly $[0]$ (Fig. 17). Define $$G \;=\; \mathrm{EL}_D(R) \;\cong\; \mathrm{EL}_9(R), \qquad \Gamma \;=\; \mathrm{EL}_\alpha(R) \;\cong\; \mathrm{EL}_3(R).$$

Three bookkeeping facts, each one line:

  • $e_\alpha = e_0$: $e_{000} + e_{001} + e_{01} = e_{00} + e_{01} = e_0$ by Lemma J(3) twice. So $\Gamma$'s corner is the cylinder $[0]$: via $\Theta_D$, $\Gamma = \{\Theta_D(\mathrm{diag}(A, I_6)) : A \in \mathrm{EL}_3(R)\}$ — the block-diagonal copy acting on the three $\alpha$-leaves and fixing the six others.
  • $\Gamma \le G$: every elementary $\alpha$-root $1 + s_{\alpha_i} r t_{\alpha_j}$ is literally an elementary $D$-root ($\alpha$-leaves are $D$-leaves), so the generators of $\Gamma$ lie among the generators of $G$. Hence $\Gamma \le G \le R^\times$.
  • Both are infinite: for fixed distinct leaves $a, b$, the map $r \mapsto 1 + s_a r t_b$ is an injective homomorphism from the infinite additive group $(R, +)$ into the elementary group (Lemma L(1) gives the homomorphism property; injectivity because $t_a(s_a r t_b)s_b = r$ recovers $r$).
Milestone. $\Gamma \le G \le R^\times$ are infinite, finitely generated (Lemma L), and both have property (T) (Import 3, transported along the isomorphisms $\mathrm{EL}_E(R) \cong \mathrm{EL}_q(R)$; property (T) is an isomorphism invariant). The pair $(\Gamma, G)$ is ready to be the $(\Gamma, G)$ of Proposition 2.3. Still needed: the compressions $u, v$ and the commuting copy $J$ of Thompson's group $V$.
