6. Thompson's group inside the unit group

Next, the obstruction group. §2.1 defined Thompson's group $V$ as prefix replacements of infinite binary strings; the Leavitt algebra realizes each replacement as a unit of $R$, by the standard construction [BS16, §2.2]. For a prefix-replacement table $g : E \to E'$ between complete codes ($a_i \mapsto b_i = g(a_i)$), set $$U_g \;=\; \sum_{a \in E} s_{g(a)}\, t_a, \qquad U_{g^{-1}} \;=\; \sum_{a \in E} s_a\, t_{g(a)}.$$ Read the first sum in the string model: $t_a$ strips the prefix $a$ (killing strings outside $[a]$), then $s_{g(a)}$ installs the prefix $g(a)$ — exactly “replace $a$ by $g(a)$, keep the tail”, done simultaneously for all table rows (Fig. 18).

Lemma M (the realization $g \mapsto U_g$ is a well-defined faithful homomorphism).
  1. $U_g U_{g^{-1}} = U_{g^{-1}} U_g = 1$, so $U_g \in R^\times$.
  2. $s_b t_a = s_{b0}t_{a0} + s_{b1}t_{a1}$; hence refining one table row $a \mapsto b$ into the two rows $a0 \mapsto b0$, $a1 \mapsto b1$ leaves $U_g$ unchanged, and $U_g$ depends only on the prefix replacement $g$, not on the table chosen.
  3. $U_h U_g = U_{h \circ g}$ and $U_{\mathrm{id}} = 1$; the map $g \mapsto U_g$ is an injective homomorphism $V \hookrightarrow R^\times$. We write $V \le R^\times$ for its image, and $V_l \le R^\times$ for the copy supported in the cylinder $[l]$ (§2.1).
  4. Every $g \in V_l$ satisfies $g - 1 \in e_l R e_l. \tag{15}$

(1) $U_g U_{g^{-1}} = \sum_{a, a' \in E} s_{g(a)} (t_a s_{a'}) t_{g(a')} = \sum_{a} s_{g(a)}t_{g(a)} = e_{E'} = 1$, using $t_a s_{a'} = \delta_{aa'}$ (Lemma J(1)) and completeness of the range code $E'$ (Lemma J(3)). The product in the other order is symmetric, with the roles of $E$ and $E'$ exchanged.

(2) $s_{b0}t_{a0} + s_{b1}t_{a1} = s_b s_0 t_0 t_a + s_b s_1 t_1 t_a = s_b(s_0t_0 + s_1t_1)t_a = s_b t_a$. Any two tables representing the same replacement $g$ have a common refinement (refine each until both domain codes coincide; a replacement determines the refined table); each refinement step preserves the sum.

(3) Given tables $g : E \to E'$ and $h : F \to F'$, refine both (allowed by (2)) until $E' = F$. Then $$U_h U_g = \sum_{a \in E,\, c \in F} s_{h(c)}(t_c\, s_{g(a)})t_a = \sum_{a \in E} s_{h(g(a))} t_a = U_{h \circ g},$$ again by $t_c s_{g(a)} = \delta_{c, g(a)}$. The identity table $a \mapsto a$ gives $U_{\mathrm{id}} = e_E = 1$. Injectivity: in the string model $U_g e_{a\omega} = e_{g(a)\omega}$, so $U_g$ acts on basis vectors exactly as $g$ acts on strings; distinct replacements differ on some string, hence on some basis vector, so their units differ.

(4) An element $g \in V_l$ has a table fixing every cylinder outside $[l]$: choose a complete code containing $l$'s complement-leaves as fixed rows, so $$U_g = x + \sum_{c} e_c \qquad \text{with } x = \sum_{a \subseteq [l]} s_{g(a)}t_a,$$ where the $c$ run over a prefix code with $e_l + \sum_c e_c = 1$. All words $a, g(a)$ in $x$ extend $l$, so $x = e_l\, x\, e_l \in e_l R e_l$; then $g - 1 = x + (1 - e_l) - 1 = x - e_l \in e_l R e_l$ ($e_l$ is the unit of the corner). ∎

The bridge from $V$ to the elementary groups is the cylinder swap. For prefix-incomparable words $\rho, \sigma$, the swap $\tau_{\rho,\sigma} \in V$ exchanges $[\rho] \leftrightarrow [\sigma]$ and fixes everything else; its unit is $$\tau_{\rho,\sigma} \;=\; 1 + e_\rho + e_\sigma + s_\rho t_\sigma + s_\sigma t_\rho$$ (characteristic $2$: this is “$1$ minus the two projections, plus the two exchange pieces”; on the string model it visibly swaps the two cylinders and fixes the rest). By Import 4, these swaps generate $V$. The following lemma is the chapter's Lemma 3.1, and its proof is a small miracle of characteristic $2$: a swap is a product of three elementary roots (Fig. 19).

Lemma 3.1. $V \le G$. Moreover, if $l$ extends one of the three words $\alpha_i$, then $V_l \le \Gamma$.

Case 1: $\rho$ and $\sigma$ extend different leaves of a prefix code $E = (a_1, \dots, a_q)$, say $\rho = a_i w$, $\sigma = a_j w'$ with $i \neq j$. Put $$P = s_\rho t_\sigma = s_{a_i}(s_w t_{w'})t_{a_j}, \qquad Q = s_\sigma t_\rho = s_{a_j}(s_{w'}t_w)t_{a_i},$$ so $1 + P$ and $1 + Q$ are elementary $E$-roots. The needed products, all from Lemma J(1): $P^2 = s_\rho(t_\sigma s_\rho)t_\sigma = 0$ and $Q^2 = 0$ (incomparability of $\rho, \sigma$); $PQ = s_\rho(t_\sigma s_\sigma)t_\rho = e_\rho$; $QP = e_\sigma$; and $PQP = e_\rho\, s_\rho t_\sigma = P$ (since $e_\rho s_\rho = s_\rho t_\rho s_\rho = s_\rho$). Now expand over $\mathbb F_2$: $$(1+P)(1+Q)(1+P) = (1 + P + Q + PQ)(1+P) = 1 + P + Q + PQ + P + P^2 + QP + PQP,$$ and the two copies of $P$ cancel mod $2$, $P^2 = 0$, $PQP = P$, leaving $$1 + Q + PQ + QP + P \;=\; 1 + e_\rho + e_\sigma + s_\rho t_\sigma + s_\sigma t_\rho \;=\; \tau_{\rho,\sigma}.$$ (Machine-checked in §9.) So $\tau_{\rho,\sigma} \in \mathrm{EL}_E(R)$.

Case 2: $\rho$ and $\sigma$ extend the same leaf $a_i$. Choose a different leaf $a_j$. Both pairs $(\rho, a_j)$ and $(\sigma, a_j)$ extend different leaves, so their swaps lie in $\mathrm{EL}_E(R)$ by Case 1 — here incomparability of $\rho$ (or $\sigma$) with $a_j$ holds because they extend different leaves; note $\sigma \neq \rho$ are themselves incomparable by assumption. The transposition identity $$\tau_{\rho,\sigma} = \tau_{\rho, a_j}\, \tau_{\sigma, a_j}\, \tau_{\rho, a_j}$$ — conjugating the swap $[\sigma] \leftrightarrow [a_j]$ by the swap $[\rho] \leftrightarrow [a_j]$ relabels $a_j$ to $\rho$, standard for transpositions; verified either on the string action (both sides send $\rho\omega \mapsto \sigma\omega$, $\sigma\omega \mapsto \rho\omega$, fix the rest — equality of units follows by faithfulness, Lemma M(3)) or by machine (§9) — puts $\tau_{\rho,\sigma} \in \mathrm{EL}_E(R)$.

$V \le G$: let $\tau_{\rho,\sigma}$ be any cylinder swap. Choose $k$ large enough that every word $\rho w$ and $\sigma w$ with $w \in \{0,1\}^k$ extends some leaf of the complete code $D$ (possible: $D$'s leaves have length $\le 4$, so $k = 4$ always suffices). Refinement (Lemma M(2)) splits the swap into the product of the $2^k$ disjoint smaller swaps $$\tau_{\rho,\sigma} \;=\; \prod_{w \in \{0,1\}^k} \tau_{\rho w,\, \sigma w}$$ (the factors commute — disjoint supports — and the product acts as the original swap on strings; faithfulness upgrades this to equality in $R$). Each factor's two words extend leaves of $D$, so each lies in $\mathrm{EL}_D(R) = G$ by Cases 1–2. Since the swaps generate $V$ (Import 4), $V \le G$.

$V_l \le \Gamma$ for $l$ extending $\alpha_i$: $V_l$ is generated by the swaps of cylinder pairs inside $[l]$ (Import 4 applied within $[l]$). Any such swap has both words extending $l$, hence extending the leaf $\alpha_i$ of the code $\alpha$ — the same-leaf Case 2 with $E = \alpha$ puts it in $\mathrm{EL}_\alpha(R) = \Gamma$. ∎

7. The configuration: two contractions and a commuting obstruction

All the machinery is now on the table; what remains is to wire it up so that Proposition 2.3 applies. We need: compressions $u, v$ with $\langle \Gamma, u, v \rangle = G$ and $u\Gamma u^{-1}, v\Gamma v^{-1} \le \Gamma$; and a commuting copy $J \cong V$ with $uJu^{-1} \le \Gamma$.

7.1 The two contractions $u, v$

The three prefixes $\zeta = (100, 101, 11)$ partition $[1]$. Define $u, v \in V \le G$ by the replacement tables (the chapter's equation (16)):

source prefix$\alpha_i$$\beta_i$$\nu_i$$(1 \le i \le 3)$
entry $b$ under source $a$ means: send $a\omega \mapsto b\omega$;
$\alpha_i 0$, $\alpha_i 1$ mean “append that bit”
$u$ sends to$\alpha_i 0$$\alpha_i 1$$\zeta_i$
$v$ sends to$\alpha_i 0$$\zeta_i$$\alpha_i 1$

Both rows are complete prefix replacements: the nine sources are the complete code $D$; the nine targets are, in either row, the six words $\alpha_i 0, \alpha_i 1$ (whose cylinders partition $[0]$, since the $[\alpha_i]$ partition it) together with the three $\zeta_i$ (partitioning $[1]$) — again a complete code. Both $u$ and $v$ send $[\alpha_i] \to [\alpha_i 0]$; they differ on where the $\beta$- and $\nu$-blocks go: $$u([\beta_i]) = [\alpha_i 1], \quad u([\nu_i]) = [\zeta_i], \qquad v([\beta_i]) = [\zeta_i], \quad v([\nu_i]) = [\alpha_i 1].$$ Watch the asymmetry: $u$ pulls the $\beta$-block into $[0]$, $v$ pulls the $\nu$-block into $[0]$ (Fig. 21, animated). Define the obstruction group on the first leaf of the $\beta$-block: $$J \;=\; V_{\beta_1} \;=\; V_{1000} \;\le\; G$$ ($J \le G$ by Lemma 3.1, first part — every $V_l$ is inside $V \le G$).

7.2 The direct product $\Gamma \times J$

The supports of $\Gamma$ and $J$ are the disjoint cylinders $[0]$ and $[1000]$; algebraically, the words $0$ and $1000$ are prefix-incomparable, so Lemma J gives the orthogonality $$e_0\, e_{1000} = e_{1000}\, e_0 = 0.$$ Every $g \in \Gamma$ satisfies $g - 1 \in e_0 R e_0$: the generators do ($1 + s_{\alpha_i}rt_{\alpha_j} - 1 = s_{\alpha_i}rt_{\alpha_j} = e_0(s_{\alpha_i}rt_{\alpha_j})e_0$ since $\alpha_i, \alpha_j$ extend $0$), and the property survives products: if $g - 1, h - 1 \in e_0Re_0$ then $gh - 1 = (g-1)(h-1) + (g-1) + (h-1) \in e_0Re_0$, and $g^{-1} - 1 = -g^{-1}(g - 1)$; here $g^{-1} = 1 + x$ with $x = g^{-1} - 1$ solving $x = -(g-1) - x(g-1) \in e_0Re_0$ by induction on word length… cleaner: each generator's inverse is itself an $\alpha$-root (characteristic 2), so every element of $\Gamma$ is a product of generators, and the product formula above closes the set $\{g : g - 1 \in e_0Re_0\}$ under multiplication. Meanwhile (15) gives $j - 1 \in e_{1000}Re_{1000}$ for every $j \in J$. Orthogonality kills all cross terms: $$(g-1)(j-1) \;=\; (g-1)\,e_0\,e_{1000}\,(j-1) \;=\; 0 \;=\; (j-1)(g-1),$$ and expanding both zero products: $gj - g - j + 1 = 0 = jg - g - j + 1$, so $gj = jg$. If $g = j$, then $g - 1$ lies in both corners, and any $x \in e_0Re_0 \cap e_{1000}Re_{1000}$ satisfies $x = e_0 x e_0 = e_0(e_{1000}xe_{1000})e_0 = 0$; so $g = 1$. Hence $$[\Gamma, J] = 1, \qquad \Gamma \cap J = \{1\}, \qquad \Gamma \times J \;\le\; G.$$ And by Corollary G, $J \cong V$ is finitely generated but not LEF. The trap is set; two conjugation computations spring it.

7.3 Proposition 3.2: the compressions work

Proposition 3.2. The prefix replacements $u, v$ of (16) satisfy $$u\Gamma u^{-1} \;=\; v\Gamma v^{-1} \;=\; \mathrm{EL}_{(\alpha_1 0,\, \alpha_2 0,\, \alpha_3 0)}(R) \;\le\; \Gamma, \qquad uJu^{-1} = V_{0001} \le \Gamma \tag{17}$$ and $$G \;=\; \langle \Gamma,\, u,\, v \rangle. \tag{18}$$

The conjugation rule. From the table (16), the words $\alpha_i$ are rows of $u$'s domain code with $u(\alpha_i) = \alpha_i 0$. Two one-line consequences of Lemma J(1) (with $u = \sum_c s_{u(c)}t_c$ over the nine rows $c \in D$): $$u\, s_{\alpha_i} = \sum_c s_{u(c)}(t_c s_{\alpha_i}) = s_{\alpha_i 0}, \qquad t_{\alpha_j}\, u^{-1} = \sum_c (t_{\alpha_j} s_c)\,t_{u(c)} = t_{\alpha_j 0},$$ because only the row $c = \alpha_i$ (resp. $c = \alpha_j$) survives the delta. Hence, for $g \in \{u, v\}$ (both send $\alpha_i \mapsto \alpha_i 0$), and all $i \neq j$, $r \in R$: $$g\,(1 + s_{\alpha_i} r\, t_{\alpha_j})\,g^{-1} \;=\; 1 + s_{\alpha_i 0}\, r\, t_{\alpha_j 0}.$$ As $r$ runs over $R$, the right-hand sides are exactly the elementary roots of the three-word prefix code $(\alpha_1 0, \alpha_2 0, \alpha_3 0)$, so both conjugates of $\Gamma$ equal $\mathrm{EL}_{(\alpha_10,\alpha_20,\alpha_30)}(R)$. This group lies inside $\Gamma$ because each of its roots is an $\alpha$-root in disguise: $$s_{\alpha_i 0}\, r\, t_{\alpha_j 0} \;=\; s_{\alpha_i}(s_0\, r\, t_0)t_{\alpha_j},$$ an elementary $\alpha$-root with coefficient $s_0 r t_0$. So $u\Gamma u^{-1} = v\Gamma v^{-1} \le \Gamma$: the compressions squeeze $\Gamma$ into a deeper copy of itself.

$uJu^{-1} = V_{0001} \le \Gamma$. The table sends $\beta_1 = 1000$ to $\alpha_1 1 = 0001$. Conjugation in $V$ transports supports: for $j \in V_{1000}$ with table fixing everything outside $[1000]$, the composite $u j u^{-1}$ first pulls $[0001]$ back to $[1000]$ (via $u^{-1}$), applies $j$ there, and pushes back — a prefix replacement supported in $[0001]$, acting as $j$ does with prefix $1000$ replaced by $0001$. This is a group isomorphism $V_{1000} \to V_{0001}$ (inverse: conjugate by $u^{-1}$), so $uJu^{-1} = V_{0001}$. Since $0001$ extends $\alpha_1 = 000$, Lemma 3.1 gives $V_{0001} \le \Gamma$. This proves (17).

Recovering $G$ (18). The inclusion $\langle \Gamma, u, v\rangle \le G$ is clear ($u, v \in V \le G$ by Lemma 3.1). For the converse we must produce every elementary $D$-root from $\Gamma$ and the two contractions. Partition the six $\alpha$- and $\beta$-leaves into three two-leaf blocks $C_i = \{\alpha_i, \beta_i\}$ and set $$X_i = s_{\alpha_i}t_0 + s_{\beta_i}t_1, \qquad Y_j = s_0 t_{\alpha_j} + s_1 t_{\beta_j}.$$ Two more delta computations with $u$'s table (rows $\alpha_i \mapsto \alpha_i 0$ and $\beta_i \mapsto \alpha_i 1$): $$u^{-1}s_{\alpha_i} = \sum_c s_c\, t_{u(c)} s_{\alpha_i} = s_{\alpha_i}t_0 + s_{\beta_i}t_1 = X_i, \qquad t_{\alpha_j}u = \sum_c t_{\alpha_j} s_{u(c)}\, t_c = s_0 t_{\alpha_j} + s_1 t_{\beta_j} = Y_j$$ (for the first: $t_{u(c)}s_{\alpha_i}$ survives when $u(c)$ is a prefix of $\alpha_i$ or vice versa — rows $c = \alpha_i$ ($t_{\alpha_i0}s_{\alpha_i} = t_0$) and $c = \beta_i$ ($t_{\alpha_i1}s_{\alpha_i} = t_1$); for the second: $t_{\alpha_j}s_{u(c)}$ survives for $u(c) \in \{\alpha_j 0, \alpha_j 1\}$, giving $s_0, s_1$). Hence $$u^{-1}(1 + s_{\alpha_i}\,r\,t_{\alpha_j})\,u \;=\; 1 + X_i\, r\, Y_j \qquad (i \neq j).$$ Now aim the coefficient. Write $\ell_{i,0} = \alpha_i$, $\ell_{i,1} = \beta_i$. Given a $2\times 2$ matrix $B = (b_{pq})$ over $R$, take $r = \sum_{p,q \in \{0,1\}} s_p\, b_{pq}\, t_q$; then $t_p\, r\, s_q = b_{pq}$ (Lemma J), and expanding, $$X_i\, r\, Y_j \;=\; \sum_{p,q} s_{\ell_{i,p}}\,(t_p\, r\, s_q)\,t_{\ell_{j,q}} \;=\; \sum_{p,q} s_{\ell_{i,p}}\, b_{pq}\, t_{\ell_{j,q}}.$$ Choosing $B$ with a single nonzero entry $b_{pq} = r'$ produces $1 + s_{a}r't_{b}$ for any source leaf $a \in C_i$ and target leaf $b \in C_j$ in different blocks ($i \neq j$) — all conjugates of $\Gamma$-elements by $u^{-1}$, hence in $\langle \Gamma, u\rangle$. For two leaves $a, b$ in the same block, route through a third block ($q = 9 \ge 3$ blocks… precisely, three blocks): pick any leaf $c$ of a different block; the Steinberg commutator (Lemma L(2), valid verbatim for prefix roots by the matrix-unit calculus) $$[\,1 + s_a r\, t_c,\; 1 + s_c\, t_b\,] \;=\; 1 + s_a r\, t_b$$ has both factors joining distinct blocks. Hence every elementary root on the six $(\alpha, \beta)$-leaves lies in $\langle \Gamma, u \rangle$: $\mathrm{EL}_{(\alpha,\beta)}(R) \le \langle \Gamma, u\rangle$. The identical argument with $v$ (whose table sends $\alpha_i \mapsto \alpha_i0$, $\nu_i \mapsto \alpha_i 1$) gives $\mathrm{EL}_{(\alpha,\nu)}(R) \le \langle \Gamma, v\rangle$. Finally, a root from a $\beta$-leaf $a$ to a $\nu$-leaf $b$ (or back): pick an $\alpha$-leaf $c$ and use the same commutator — the factor $1 + s_a r t_c$ lives on $(\alpha,\beta)$-leaves, the factor $1 + s_c t_b$ on $(\alpha,\nu)$-leaves, both already obtained. Swapping $a \leftrightarrow b$ gives the reverse roots. Every elementary $D$-root is now in $\langle \Gamma, u, v\rangle$, proving (18). ∎

Configuration complete. $G = \langle \Gamma, u, v\rangle$ with $u\Gamma u^{-1}, v\Gamma v^{-1} \le \Gamma$; $J \cong V$ with $[\Gamma, J] = 1$, $\Gamma \cap J = \{1\}$, $uJu^{-1} \le \Gamma$; $\Gamma, G$ infinite, finitely generated, property (T); $J$ finitely generated, not LEF. Every hypothesis of Proposition 2.3 is in hand.
